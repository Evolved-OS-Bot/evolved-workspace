# PEACH-RIG Three-Quarter Candidate v1 QA Gate

This checklist is inactive until a native `.motn` project exists.

## Native-source gate

- [ ] Motion project created through the supported graphical interface
- [ ] All 29 PNG files imported as separate stills
- [ ] Image Sequence disabled
- [ ] Embedded alpha interpreted cleanly
- [ ] Full-canvas origin and layer order verified
- [ ] Body/shading, face-field texture and left-shoe brand locked
- [ ] Neutral transparent PNG exported
- [ ] Neutral comparison has zero differing visible pixels

## Construction gate

- [ ] Anchor compensation proved before bulk pivot changes
- [ ] Anatomical-left and anatomical-right names retained
- [ ] No Flip filter or negative X scale
- [ ] Upper arms and legs attach directly to the fruit
- [ ] Foreground gloves and shoes follow their chain endpoints
- [ ] `Evolved` remains only on the anatomical-left shoe
- [ ] Fixed body-space leg-root covers use approved upper-leg pixels
- [ ] Root-cover masks are applied directly to the duplicate layers
- [ ] No root-cover rotation link used unless static coverage fails

## Stress gate

- [ ] Both leg roots tested at -12, -6, 0, +6 and +12 degrees
- [ ] Modest overtravel tested without publishing the range
- [ ] No leg-opening wedge
- [ ] No floating patch, duplicate outline or texture discontinuity
- [ ] No human thigh, hip, pelvis or peach stub
- [ ] Body tilt and two-percent squash combined test passes
- [ ] Light, dark plum and checkerboard renders pass
- [ ] Neutral reset returns to the exact approved source

## Approval boundary

- [ ] Technical QA record complete
- [ ] Rig review package complete
- [ ] Peter Brown explicitly approves the rig

Rig approval will not approve any reusable motion, expression, template,
export preset, deployment, or external handoff.
