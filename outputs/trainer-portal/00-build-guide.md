## GHL Course Setup: Standard Steps Per Course

1. Memberships → Courses → New Course
2. Enter title and description from the course file
3. Create modules and lessons: paste content from the Lessons section
4. For Courses 1–12, add a native assessment from the matching file in `quiz-csvs/` and set the pass mark to 80%
5. For Course 13, add the ten competency blocks as lessons or practical tasks and require management approval
6. Set the sequential access path through the GHL grant-access workflows
7. Release Course 14 only after Course 13 has been approved
8. Issue the final delivery credential after Practical Sign-Off approval

## Certificate Template (Set Up Once)

- Go to Memberships → Credentials → Create
- Name: `The Evolved Trainer: Certified to Deliver`
- Upload The Evolved logo
- Brand colours: use the gym's colour scheme
- Issue only after Course 13 has been approved
- The Course 14 access workflow and credential workflow must share the same approval gate

---

## Course Ordering (Sequential: Lock Each Behind Previous)

Courses must be completed in order 1 → 14. Completion of theory alone must never certify a trainer to deliver independently.
