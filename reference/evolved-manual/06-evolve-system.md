## Purpose

The EVOLVE System is the standardisation framework that ensures every Sculpt & Strength and Build & Balance class delivers the same quality experience regardless of which trainer is running it.

It solves a specific problem: without a system, two trainers setting up the same exercise class will make different decisions about station layouts, equipment weights, and exercise progressions. Members get an inconsistent experience. Trainers waste time deciding what to set up. New trainers are left to improvise.

The EVOLVE System removes improvisation from class setup and exercise selection. Every station, every exercise, every regression and progression is defined in advance. The trainer's job is to coach — not to invent.

## The Weight Tier System

Every exercise in the EVOLVE System is pre-configured across **three weight tiers**. When setting up for class, the trainer assigns each member to a tier before they begin. This determines which station they use and what equipment is already there when they arrive.

| Tier | Working Weight |
|---|---|
| Tier 1 | <20kg |
| Tier 2 | 20kg> |
| Tier 3 | 40kg> |

**Why this matters:** When 5 members need 20–30kg for a squat and 3 members need 50kg+, grouping by tier means racking and unracking is minimal, equipment is pre-loaded, and transitions between exercises are fast. The trainer spends time coaching, not reconfiguring the gym.

**Practical setup:** Before class, the trainer identifies the day's main exercise and sets up all 6 platforms according to the EVOLVE floor card for that exercise. Each card shows the exact equipment required per tier.

## The Regression/Progression Framework

For every exercise, the EVOLVE System defines a **regression/progression spectrum** — a horizontal arrow showing exercise options from easiest (left) to most advanced (right).

**How trainers use this:**
- The prescribed program specifies the exercise type (e.g., Deadlift, Squat, Row)
- The trainer identifies where the member currently sits on the spectrum
- If a member cannot perform the prescribed exercise with good form, regress left
- If a member is progressing beyond the prescribed exercise, progress right — but only within the EVOLVE-defined options

**The constraint is intentional.** Trainers do not invent progressions or regressions. They use what is on the card. This ensures quality control, safety, and program integrity across all trainers and all members.

### 10. Deadlift — Romanian Deadlift / Conventional Deadlift / All Variations

**Movement pattern:** Hip-dominant hinge

**Tier equipment setup:**

| Tier | Station label | Equipment |
|---|---|---|
| <20kg | Dowel or Dumbbell | Dowel, 1.25kg Plates, 4kg Dumbbells, 7kg Dumbbells |
| 20kg> | Barbell or Dumbbell | 2kg Dumbbells, 6kg Dumbbells, 9kg Dumbbells, 20kg Barbell, 2×2.5 Plates, 2×5 Plates, 2×10kg Plates |
| 40kg> | Barbell or Dumbbell | 3kg Dumbbells, 20kg Barbell, 2×5 Plates, 2×2.5 Plates, 2×10kg Plates |

**Canonical Hinge Regression/Progression:**

| Stage | Exercise |
|---|---|
| 1 | Broomstick Hinge |
| 2 | Dumbbell Romanian Deadlift |
| 3 | Barbell Romanian Deadlift |
| 4 | Trap Bar Deadlift |
| 5 | Barbell Deadlift |

**Coaching notes for deadlift progression:**
- Height adjustments (using plates or rack) allow the range of motion to be shortened for members who cannot yet maintain a neutral spine through a full conventional deadlift
- Progress height toward the floor as spinal control improves
- Broomstick Hinge establishes the hinge pattern before loading
- Apply PRIME to every rep and advance only after 10 pain-free, repeatable reps remain below 7 RPE
- Before progressing from Barbell Romanian Deadlift to Trap Bar Deadlift, require 12 reps at 35 kg total barbell load. Every rep includes a controlled one-second hold just below mid-knee in a PRIME postural position
- Stop at the highest exercise the member performs proficiently at about 7 RPE
- If PRIME, comfort or safety breaks down, return to the previous proficient exercise

## The Physical Cards

The EVOLVE System lives as a set of **laminated floor cards stored in the back left corner of the gym**. One card per exercise group, double-sided:
- Front: gym floor layout with tier equipment lists for that exercise
- Back: regression/progression spectrum for that exercise

These cards are the live version of this system. If the cards and this document ever differ, the cards take precedence — the cards reflect the current physical setup of the gym.

Trainers are expected to know where the cards are and pull the correct one before every class.

## Using the EVOLVE System in Class

### Before the session

1. Check the Trainerize workout — identify the main lift and any secondary exercises
2. Go to the back left corner of the gym — pull the correct EVOLVE floor card(s)
3. Assign each member a tier before they arrive (based on their last recorded working weight in Trainerize)
4. Set up all 6 platforms per the card specifications

### During the session

1. When a member arrives, direct them to their tier station — equipment is already there
2. Members open Trainerize, confirm their working weight, and proceed with the Performance Warm-Up
3. If a member needs a regression or progression during the set, use the spectrum on the card — do not improvise
4. Actively preempt setup changes as the session moves between exercises

### Common mistakes

| Mistake | Why it matters | Correction |
|---|---|---|
| Improvising a regression not on the card | Creates inconsistency across trainers — same member gets different cues week to week | Use only the EVOLVE-defined options |
| Skipping tier pre-assignment | Members arrive uncertain, waste time selecting equipment | Assign tiers from Trainerize data before class |
| Setting up equipment mid-session | Trainer turns back to members to rearrange | Pre-set fully before class, preempt transitions during |
| Using a different progression for an advanced member | Program integrity is lost | Deliver what is prescribed — flag to management if you believe a member has outgrown the current tier |

## Why Standardisation Produces Better Results

The EVOLVE System is not about rigidity — it is about what consistency produces over time.

When a member trains at The Evolved three times per week for a year, they will be coached by multiple trainers. If each trainer uses different progressions, different cues, and different equipment setups, that member builds an inconsistent movement pattern. Progress is slower. Risk of injury is higher.

When every trainer delivers the same progressions, uses the same cues, and pre-sets stations the same way, the member's experience is coherent. Their body learns the same movement patterns repeatedly. Progress compounds.

The EVOLVE System is the delivery mechanism for that coherence.
