# SOP: Trainerize Program Cycle Duplication

**System:** ABC Trainerize
**Gym:** The Evolved All Female Gym
**Owner:** Peter & Megan Brown
**Status:** Draft, training in progress
**Effective Date:** Not yet live
**Version:** 0.1

---

## 1. Purpose

Create the next program cycle for an existing client by duplicating their most recently completed phases in Trainerize.

This preserves the completed program as the base for later renaming and client-specific adjustments.

---

## 2. Scope

This draft covers the duplication step only. It does not yet cover renaming phases, changing exercises, adjusting sets or reps, scheduling workouts, or publishing member communications.

The current verified example uses a four-phase cycle:

1. Foundations: 4 weeks
2. Building: 4 weeks
3. Performance: 4 weeks
4. De-load: 1 week

---

## 3. Before You Start

- Confirm that the correct client profile is open.
- Open **Training Program** from the client navigation.
- Confirm that you are working inside the client's main custom program.
- Identify the most recently completed four-phase cycle, beginning with Foundations.
- Record the source phase names, order, start dates, end dates, and durations.
- Confirm that no future duplicate cycle already exists.

Do not change or delete the completed source phases.

---

## 4. Duplication Procedure

Duplicate the phases in chronological order. Complete and save each duplicate before starting the next one.

### Step 1: Duplicate Foundations

1. Find the most recently completed Foundations phase.
2. Click the three-dot menu beside the phase.
3. Select **Duplicate**.
4. Review the **Save Training Phase As** window.
5. Confirm the new phase starts on the day after the client's previous program ends.
6. Confirm the duration matches the source phase, normally 4 weeks.
7. Confirm the proposed phase name follows the client's current sequence.
8. Click **Save**.

### Step 2: Duplicate Building

Repeat the same process using the completed Building phase. Confirm that it begins immediately after the new Foundations phase and retains its original duration, normally 4 weeks.

### Step 3: Duplicate Performance

Repeat the same process using the completed Performance phase. Confirm that it begins immediately after the new Building phase and retains its original duration, normally 4 weeks.

### Step 4: Duplicate De-load

Repeat the same process using the completed De-load phase. Confirm that it begins immediately after the new Performance phase and retains its original duration, normally 1 week.

Trainerize may suggest a copied name rather than the next numbered phase name. Leave naming changes for the approved renaming step unless the trainer responsible for the program has provided the final name.

---

## 5. Verification Checklist

Before closing Trainerize, confirm:

- Four new phases appear after the completed cycle.
- The new cycle follows Foundations, Building, Performance, then De-load.
- There are no gaps or overlaps between phase dates.
- The durations match the source phases.
- The duplicated phases contain the same workouts as their source phases.
- The original completed phases remain unchanged.
- No blank phase was created accidentally.
- The main program end date now matches the end of the duplicated De-load phase.

---

## 6. Do Not Use for This Task

Do not use **+ Add next** when the goal is to copy an existing phase. This creates a blank training phase.

Do not use **Import from** for a direct duplication of phases already inside the same client's program. Use the phase's three-dot menu and select **Duplicate**.

Do not select **Edit** from the three-dot menu. Close the edit window without saving if it opens accidentally.

---

## 7. Recovery and Escalation

If a blank phase is created accidentally, do not add workouts or make further changes. Confirm the phase is empty, then remove it using the approved deletion process or ask Peter or Megan to review it.

If dates overlap, a duration differs from the source, or the program sequence is unclear, stop before saving. Ask Peter or Megan to confirm the intended dates and phase order.
